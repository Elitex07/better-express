# Security Policy

## Supported Versions

Only the latest major version of BareWeb is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in BareWeb, please do **NOT** open a public issue. 

Instead, please report it privately via the [GitHub Security Advisories](https://github.com/Elitex07/better-express/security/advisories) page by clicking "Report a vulnerability", or email the maintainer directly if an email is provided on their GitHub profile.

We will review all security reports and work with you to patch the vulnerability and safely disclose it.
